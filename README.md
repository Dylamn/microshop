# MicroShop

MicroShop is a modular e-commerce platform demonstrating a microservices' architecture.

Built with `FastAPI`, `Angular`, `Keycloak` and `Apache APISIX`, fully orchestrated with `Docker Compose`.

Features will include:

- User authentication
- Product and order management
- Caching
- Service-to-service communication.

## Installation

To run it locally, you need to have `Docker` and `Docker Compose` installed.

With them, run:

```shell
docker-compose up --build 
```

> Add `-d` to run it in background.
